输入访问口令

口令由服务提供者单独发放，只保存在这台手机的 localStorage 里。页面每次发送时把它放进 Authorization 头。不存 Cookie：接口的跨域策略会原样回显任意来源， 存 Cookie 等于允许别的网站借用你的凭证。

这一页在做什么

页面托管在 GitHub Pages，问答走一个函数计算接口，接口后面是百炼智能体应用。 接口地址来自上方设置项，备案换域名之后只需改那一行，页面代码不用动。

回答是流式的：文字一段一段到达，最后一段的 finish_reason 为 stop 才算说完。 多轮对话靠服务端返回的 session_id 续上；官方说明连续 1 小时无请求该 id 会失效， 失效时页面会自动开新会话重发。
